# customer-clustering
Machine Learning project on Customer Segmentation with K-Means.  Contains clustering analysis and a Streamlit app for visualization.
# Customer Segmentation using K-Means Clustering

This project applies **unsupervised machine learning (K-Means clustering)** to segment mall customers based on their **Age, Income, and Spending Score**.  
It also includes a **Streamlit web app** for interactive visualization.

---

## 📊 Project Files
- `Jupyter.ipynb` → Full notebook with analysis, clustering, and visualizations.  
- `app.py` → Streamlit app for interactive demo.  
- `Mall_Customers.xlsx` → Original dataset from Kaggle.  
- `mall_customers_with_clusters.xlsx` → Dataset with assigned clusters.  
- `requirements.txt` → Python dependencies list.
